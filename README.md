# StreamBlur — автоблюр фильма в OBS по таймингам

Программа для стримеров: в нужные моменты фильма (сцены насилия / наготы, которые запрещает
Twitch TOS) **весь захват экрана с фильмом мгновенно закрывается размытием**, и так же
мгновенно снимается, когда сцена кончилась.

```
┌─────────────┐    ┌──────────────────┐    ┌─────────────────┐    ┌──────────┐
│ Сайт/плеер  │───▶│  RealtimeClock   │───▶│  BlurEngine     │───▶│   OBS    │
│ (таймер)    │    │  OCR / DOM / hotkey│  │ (тайминги + сдвиг)│   │ (фильтр) │
└─────────────┘    └──────────────────┘    └─────────────────┘    └──────────┘
                             ▲                      ▲
                    ┌────────┴─────────┐   ┌────────┴─────────┐
                    │ TimingsProvider  │   │   FilmsDB        │
                    │ (сайт по выбору) │   │ год/студия/комп. │
                    └──────────────────┘   └──────────────────┘
```

## Что умеет

| Модуль | Что делает |
|---|---|
| **Полноэкранный блюр** | Включает/выключает фильтр размытия на источнике захвата через `obs-websocket v5` |
| **Тайминги с сайта** | Провайдеры: локальный JSON/SRT/VTT, OpenSubtitles, TMDB, IMDb, «Generic» (свой сайт по URL + селекторам) |
| **База фильмов** | Год производства, студии, компании-производители, страна, жанры; SQLite; ручной импорт и поиск по названию |
| **Автообновление** | Раз в **день / неделю / месяц** — выбирается в UI, планировщик внутри приложения |
| **Чтение таймера** | OCR цифр `0:12:34` с любой области экрана (работает с ЛЮБЫМ плеером/сайтом), DOM/CDP для браузеров, ручная синхронизация хоткеем |
| **Мультиязычность** | Интерфейс RU/EN, тайминги и метаданные для любого языка (`language` у провайдера, `ru-RU`, `en-US`, `de-DE`, …) |
| **Веб-интерфейс** | localhost-панель: настройка, библиотека, тайминги, живая синхронизация, лог, **кнопка PANIC** |
| **Demo-режим** | `mock-obs` — полноценный тест всей цепочки без установленного OBS |

## Быстрый старт (без OBS, за 30 секунд)

```bash
git clone https://github.com/<вы>/streamblur.git
cd streamblur
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m streamblur demo        # поднимет мок-OBS + мок-плеер + UI
```
Открыть → http://127.0.0.1:8765 → вкладка **Демо** → «Запустить демо».
Через несколько секунд фильм «дойдёт» до опасной сцены и экран заблюрится.

## Быстрый старт (с реальным OBS)

1. OBS → **Инструменты → Настройки obs-websocket** → включить, запомнить порт/пароль.
2. OBS → на источник с фильмом → **Фильтры → + → Размытие** (см. `docs/SETUP_OBS.md`,
   какие фильтры поддерживаются).
3. Запустить: `streamblur ui` → http://127.0.0.1:8765 → вкладка **Подключение** → «Подключить OBS».
4. Вкладка **Синхронизация** → выделить область с таймером плеера → «Тест OCR».
5. Вкладка **Библиотека** → найти фильм → подтянуть тайминги → **GO**.

## Дисклеймер

StreamBlur — инструмент **снижения риска** для стримера, а не гарантия. Он не заменяет
предварительный просмотр материала. Всегда держите под рукой горячую клавишу «PANIC»
(полный блюр) и сцену-заглушку в OBS. Ответственность за контент на стриме несёт стример.

## Страховка (нейросеть)

Тайминги могут врать, поэтому поверх них работает страховка: нейросеть смотрит
на кадр и включает блюр сама. По умолчанию выключена и работает в режиме
проверки — сначала убедитесь, что срабатывания адекватные.

```bash
python -m streamblur safety-models --download   # скачать модели
python -m streamblur safety-check --frames 60   # проверить лично
```

Честные цифры, что ловит и что нет — в [docs/SAFETY.md](docs/SAFETY.md).
Коротко: нагота ловится (0.96 на реальном фото), кровь — **нет**, для неё нужна
другая модель.
