# Как собрать EXE через GitHub — пошагово

Ни одного действия на своей машине делать не нужно: сборка идёт на серверах GitHub
бесплатно (для публичного репозитория — без ограничений, для приватного — 2000
минут в месяц на бесплатном тарифе, одна сборка занимает ~6–10 минут).

В результате получаются два файла:

| Файл | Что это | Кому |
|---|---|---|
| `StreamBlur-portable-<версия>.zip` | папка с программой, распаковал — работает | кто не хочет ничего устанавливать |
| `StreamBlur-Setup-<версия>.exe` | обычный установщик с ярлыками | обычный пользователь |

---

## Шаг 1. Завести репозиторий

1. Откройте <https://github.com/new>.
2. **Repository name**: `streamblur`.
3. **Public** — рекомендую: для публичных репозиториев сборка бесплатна и без
   лимита минут.
   ⚠️ Проект распространяется под **AGPL-3.0**, а эта лицензия **требует**,
   чтобы получатель EXE мог взять исходный код. Публичный репозиторий закрывает
   это требование само по себе.
4. **Add a README** — НЕ ставьте (файлы уже есть локально, иначе будет конфликт).
5. **Create repository**.

## Шаг 2. Загрузить код

В папке с проектом:

```bash
cd streamblur
git init -b main
git add .
git commit -m "StreamBlur: автоблюр фильма для OBS"
git remote add origin https://github.com/ВАШ_ЛОГИН/streamblur.git
git push -u origin main
```

Если Git попросит представиться:

```bash
git config --global user.name  "Ваше Имя"
git config --global user.email "вы@example.com"
```

> Проверьте, что в репозиторий **не** попала папка `data/` с вашей базой фильмов
> и `settings.json` — они в `.gitignore`.

## Шаг 3. Запустить сборку

### Вариант А — кнопкой (проще всего)

1. Вкладка **Actions** → слева **Сборка EXE**.
2. Справа **Run workflow** → ветка `main` → **Run workflow**.
3. Ждите 6–10 минут. Зелёная галочка = готово.

> Если вкладки Actions нет: **Settings → Actions → General → Actions permissions**
> → выберите **Allow all actions and reusable workflows**.

### Вариант Б — по версии (так делают релизы)

```bash
git tag v0.1.0
git push origin v0.1.0
```

Тег `v*` запускает сборку **и** автоматически создаёт релиз в
**Releases** с обоими файлами — оттуда их удобно скачивать и раздавать.

## Шаг 4. Скачать результат

**После варианта А:** зайдите в этот запуск workflow → внизу раздел
**Artifacts** → `streamblur-windows` → скачается zip, внутри оба файла.

**После варианта Б:** вкладка **Releases** → последний релиз → в **Assets**
лежат `StreamBlur-portable-…zip` и `StreamBlur-Setup-…exe`.

---

## Проверка, что сборка живая

Workflow не просто собирает, а **запускает** собранный EXE с командой `doctor`
и роняет сборку, если программа не стартовала. То есть «собралось, но не
работает» до релиза не доедет.

## Собрать у себя на Windows (без GitHub)

Понадобится Python 3.12+ с <https://python.org> (при установке поставьте
галочку **Add python.exe to PATH**).

```bat
cd streamblur
python -m pip install -r requirements.txt
python -m pip install pyinstaller
python -m PyInstaller packaging\streamblur.spec --noconfirm --clean
```

Готово: папка `dist\StreamBlur\`, внутри `StreamBlur.exe`.

### Добавить установщик

1. Установите Inno Setup 6: <https://jrsoftware.org/isdl.php>.
2. Соберите EXE командой выше.
3. Запустите:

```bat
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" packaging\installer.iss
```

Установщик появится в `packaging\Output\`.

### Один файл вместо папки

```bat
set ONEFILE=1
python -m PyInstaller packaging\streamblur.spec --noconfirm --clean
```

Честно про разницу: однофайловый EXE при каждом запуске распаковывает себя во
временную папку — это плюс 5–20 секунд к старту. Папка стартует за секунду и
весит столько же. Поэтому по умолчанию собирается папка, а вариант «двойной клик — и работает» даёт установщик.

## Версия программы

Версия указана в трёх местах — при выпуске новой меняйте все три:

| Где | Что |
|---|---|
| `streamblur/__init__.py` | `__version__ = "0.1.0"` |
| `packaging/installer.iss` | `#define MyAppVersion "0.1.0"` |
| тег Git | `v0.1.0` |

## Если что-то пошло не так

**«StreamBlur.exe не запускается, Windows защитил ваш компьютер»**
Это SmartScreen ругается на неподписанную программу, а не на ошибку. Нажмите
**Подробнее → Выполнить в любом случае**. Лечится навсегда только платной
подписью кода (сертификат ~$200–400/год) — для бесплатной программы обычно не
покупают.

**Антивирус удаляет EXE**
Ложное срабатывание на упаковщик PyInstaller, это массовая проблема таких
сборок. Добавьте папку программы в исключения. Именно поэтому в репозитории
есть обычный запуск через Python — он не triggering антивирус.

**Сборка упала на шаге «pytest»**
Значит в код попала ошибка. Откройте упавший шаг в Actions — там полный вывод
тестов. Чинить надо до сборки, а не обходить: в workflow тесты стоят первыми
именно для этого.

**Сборка упала на «ISCC.exe не найден»**
Inno Setup не установился. Перезапустите workflow; если повторится — в шаге
*Установить Inno Setup 6* замените `choco install innosetup` на скачивание
`innosetup-6.*.exe` с <https://jrsoftware.org/isdl.php> и тихую установку ключом
`/VERYSILENT`.

**Хочу собрать без OCR (легче на ~110 МБ)**
OCR тянет `rapidocr-onnxruntime`, `onnxruntime` и OpenCV. Уберите из
`requirements.txt` строки про `rapidocr-onnxruntime` и `opencv-python-headless`,
а в `packaging/streamblur.spec` — строку `datas += collect_data_files("rapidocr_onnxruntime")`.
Тогда время фильма придётся читать через расширение браузера или вводить руками
— программа это умеет, источник времени выбирается в настройках.

## Что лежит в `packaging/`

| Файл | Зачем |
|---|---|
| `streamblur.spec` | что именно кладём в EXE: интерфейс, модели OCR, данные |
| `entry.py` | точка входа: двойной клик = открыть панель; авария пишется в `streamblur-crash.log` |
| `installer.iss` | сценарий установщика: ярлыки, русский язык, без прав администратора |
| `../.github/workflows/build.yml` | сама сборка: тесты → EXE → установщик → релиз |
